# CADENCE

**Container Supply Chain Patch Latency Measurement**

CADENCE measures end-to-end patch latency in multi-hop container supply chains
by polling public Red Hat data sources and computing the time between RHSA
publication and the appearance of fixed packages in successively-downstream
container images.

> This README is a skeleton. The full README is delivered in WP-13.
